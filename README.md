Agent skills from Brinker Analytics.

## marketing-data-lake

Walks your AI agent through building a marketing data lake your brand owns. It loads orders (Shopify), ad platforms (Google Ads, Meta, and others), GA4, and Search Console into BigQuery on a schedule. It joins them into daily views and writes the SQL for your first questions. You fill in your own connection details, and secrets stay in Secret Manager, never in files.

## Install

```bash
npx skills add brinkereric-png/brinker-analytics-skills
```
